Strings in C

a beginner's personal guide

By Akriti Singh — 1st Semester BCA student

I'm sharing my actual learning notes from the past lab sessions. When I started C, storing numbers was pretty basic and simple, but strings were very different — difficult to understand at first. Here are my learnings, shared as I wrote them down.

1. From numbers to words

In the initial lectures of C programming, everything was about integers and floats — calculating average marks or checking passing grades using conditional statements. Then my professor introduced strings and their functions. That's when I realized: there's more to it.

the core idea

A string is essentially a collection of characters — letters, symbols, or numbers — treated as a single text unit. Words like "AKRITI" or "BENGALURU" are strings. But behind the scenes, C stores them using an array of type char.

2. What is a string in C?

A string is really a character array, where each character sits in its own slot in memory, one after another. For instance, when we declare:

char arr[] = "Akriti";

Here is how C actually stores it inside the computer's memory cells:

A[0]
K[1]
R[2]
I[3]
T[4]
I[5]
\0[6]

seven memory cells for a six-letter word — notice index [6]

3. The twist: the null character

That extra cell at index [6] holding \0 is the null character — one of the most confusing things for me at first. Because C character arrays don't automatically keep track of their own size, C uses \0 as a stop signal that tells the compiler where the text ends. Without it, your program would keep reading random garbage memory past your actual text.

did you know?

A word with 6 letters (like "AKRITI") actually requires 7 memory slots in C. You must always allocate one extra space for the hidden \0 byte, or your program will return garbage values or weird output.

4. Declaring and initializing strings

You can declare a string in two simple ways:

char name[20]; char name[] = "BCA Student";
DeclarationMeaning
char name[20];Reserves space for up to 19 characters + 1 null character.
char name[] = "BCA Student";Automatically calculates size — 11 characters + 1 = 12 bytes.

5. Taking string input

One common beginner point: a string stored in a character array is entered differently from a normal integer variable.

scanf("%s", firstName);
watch out

We wrote scanf("%s", firstName); without an ampersand (&). That's because an array name itself acts as a memory address pointer — adding & is a habit from integers that beginners often accidentally repeat here.

a small memory reminder

The easiest way to remember strings: characters are stored one after another, and \0 marks where the string ends.

6. Handy functions in <string.h>

Instead of manually counting characters using loops, C gives us standard built-in functions inside the #include <string.h> header file:

FunctionSyntaxPurpose
strlen()strlen(string);Finds the length of a string
strcpy()strcpy(dest, src);Copies the source string to destination
strncpy()strncpy(dest, src, n);Copies up to n characters
strcat()strcat(s1, s2);Joins / appends string2 to string1
strncat()strncat(s1, s2, n);Joins up to n characters of string2
strcmp()strcmp(s1, s2);Compares two strings — 0 if equal, <0 if s1 before s2, >0 if s1 after s2
strncmp()strncmp(s1, s2, n);Compares the first n characters

these functions save time and keep code compact

7. Real-life connection: student registration

Almost every real application — from college web portals to login forms — uses strings. A student's name, city, category, and other text-based information are all data that can be stored as strings.

#include <stdio.h> int main() { char studentName[30], city[20]; }

why strings matter

Numbers let programs calculate, but strings allow our C code to actually interact and talk with human users. That's why understanding character arrays is worth the effort, even though strings feel confusing at first.

9. Conclusion

Switching from numbers to strings felt like a jump at first, but understanding that a string is just a character array ending with \0 made everything click for me. Numbers let programs calculate, but strings let our C code actually interact and talk with human users.

My key takeaways

  • A string in C is stored using a character array.
  • Every string needs a null character (\0) at the end.
  • The <string.h> header provides useful string functions.
  • String comparison should be done using strcmp(), not ==.
  • Enough array space should be provided to avoid overflow.
